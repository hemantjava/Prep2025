Here’s a simple diagram illustrating the **Original Binary Tree** and the **Mirrored Binary Tree**.
### ✅ Original Binary Tree:

```
        1
      /   \
     2     3
    / \   / \
   4   5 6   7
```

---

### ✅ Mirrored Binary Tree:

```
        1
      /   \
     3     2
    / \   / \
   7   6 5   4
```

---

### ✅ How It Works:

* Every node’s left and right children are swapped.

This simple visual helps you understand the in-order traversal results:

* Original In-order → `4 2 5 1 6 3 7`  -> parent node should be in middle
* Mirrored In-order → `7 3 6 1 5 2 4`
